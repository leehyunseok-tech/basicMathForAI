> 순서대로 읽는 자료가 아닙니다. **모르는 기호가 나올 때 찾아보는 사전**입니다.

## 그리스 문자

| 기호 | 읽는 법 | AI에서 보통 이런 뜻 |

| $\theta$ | 세타 | 모델이 학습하는 값 전체 (파라미터) |
| $\eta$ | 에타 | 학습률 (learning rate) |
| $\alpha$ | 알파 | 학습률, 또는 조절 계수 |
| $\lambda$ | 람다 | 정규화 강도 등 조절 값 |
| $\sigma$ | 시그마 (소문자) | 표준편차, 또는 시그모이드 함수 |
| $\Sigma$ | 시그마 (대문자) | **전부 더하기** |
| $\mu$ | 뮤 | 평균 |
| $\epsilon$ | 엡실론 | 아주 작은 수 (0으로 나누기 방지용) |
| $\nabla$ | 나블라 / 그래디언트 | 기울기 벡터 |
| $\partial$ | 라운드 / 델 | 편미분 |

## 첨자 읽는 법

| 표기 | 뜻 |
|---|---|
| $x_1, x_2, x_i$ | **아래** 첨자 = 몇 번째 (코드의 `x[i]`) |
| $W^{(2)}$ | **위 첨자 + 괄호** = 2층의 W (제곱 아님!) |
| $W^2$ | 위 첨자만 = 제곱 |
| $x_{ij}$ | i행 j열 (행렬의 한 칸) |

> ⚠️ **괄호 유무가 전부입니다.** $W^{(2)}$ 는 층 번호, $W^2$ 는 제곱.

## 집합 · 논리 기호

| 기호 | 읽는 법 | 뜻 |
|---|---|---|
| $\in$ | 원소이다 | $x \in A$ = x는 A에 속한다 |
| $\subset$ | 부분집합 | |
| $\cup$ / $\cap$ | 합집합 / 교집합 | |
| $\mathbb{R}$ | 실수 전체 | $x \in \mathbb{R}^{768}$ = 768차원 실수 벡터 |
| $\forall$ | 모든 | |
| $\exists$ | 존재한다 | |
| $\mid$ | ~라는 조건에서 | $P(A \mid B)$ (Ch 14) |

> 💬 $x \in \mathbb{R}^{768}$ 은 논문에서 아주 자주 봅니다.
> **"x는 숫자 768개짜리 벡터다"** 라는 뜻입니다.

## 자주 보는 함수

| 표기 | 하는 일 | 배운 곳 |
|---|---|---|
| $\sigma(x)$ | 시그모이드 — 0~1 사이로 | Ch 08 |
| $\text{ReLU}(x)$ | 음수는 0, 양수는 그대로 | Ch 08 |
| $\text{softmax}(z)$ | 여러 값을 확률로 (합 = 1) | Ch 08 |
| $\log x$ | 로그 (밑 생략 시 대개 자연로그) | Ch 07 |
| $\exp(x)$ 또는 $e^x$ | 지수 | Ch 07 |
| $\max(a, b)$ | 둘 중 큰 값 | — |
| $\arg\max$ | **최댓값이 나오는 위치(번호)** | — |

> 💬 $\arg\max$ 는 헷갈리기 쉽습니다.
> $\max$ 는 **값**을, $\arg\max$ 는 **몇 번째인지**를 돌려줍니다.
> 분류에서 "가장 확률 높은 클래스 번호"를 고를 때 씁니다.

## 자주 만나는 통짜 수식

| 수식 | 한국어로 |
|---|---|
| $\hat{y} = wx + b$ | 입력에 가중치 곱하고 편향 더하면 예측 |
| $L = \frac{1}{n}\sum (y_i - \hat{y}_i)^2$ | 오차를 제곱해 전부 더한 뒤 평균 |
| $L = -\sum y_c \log \hat{y}_c$ | 정답에 준 확률의 로그, 부호 뒤집기 |
| $\theta \leftarrow \theta - \eta \nabla L$ | 가장 가파른 방향 반대로 한 발 |
| $\text{softmax}(z_i) = \frac{e^{z_i}}{\sum_j e^{z_j}}$ | 양수로 만들고 합이 1이 되게 나누기 |
