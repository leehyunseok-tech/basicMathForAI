## E.3 방향별 다음 공부

**전부 할 필요 없습니다.** 관심 가는 것 하나만 고르세요.

### 🔷 트랜스포머·LLM을 제대로 알고 싶다면 → 선형대수

| 배울 것 | 왜 |
|---|---|
| 행렬 분해 (SVD, 고유값) | 차원 축소, LoRA 같은 기법의 기반 |
| 행렬의 랭크 | "저랭크 근사"가 왜 되는지 |
| 텐서 (3차원 이상 배열) | 배치 × 시퀀스 × 차원 다루기 |

> Chapter 09~11에서 배운 벡터·행렬의 **확장판**입니다. 새로운 세계가 아닙니다.

### 🔷 생성 모델·불확실성에 관심 있다면 → 확률·통계

| 배울 것 | 왜 |
|---|---|
| 확률분포 (베르누이, 가우시안) | VAE, 디퓨전 모델의 기반 |
| 최대우도추정 (MLE) | 손실 함수가 어디서 왔는지 |
| KL 발산 | 두 분포가 얼마나 다른지 재는 법 |
| 베이지안 추론 | 모델의 확신도 다루기 |

> Chapter 13~15의 확장입니다. 특히 **크로스엔트로피가 왜 그 모양인지**를 제대로 알게 됩니다.

### 🔷 학습이 안 될 때 원인을 알고 싶다면 → 최적화

| 배울 것 | 왜 |
|---|---|
| Adam, RMSProp, 모멘텀 | Ch 18 칼럼에서 이름만 나왔던 것들 |
| 학습률 스케줄링 | 보폭을 언제 줄일까 |
| 정규화 (L1, L2, 드롭아웃) | 과적합 막기 |
| 배치 정규화 | 학습 안정화 |

> **가장 실무적인 방향**입니다. 모델이 학습이 안 될 때 뭘 만져야 할지 알게 됩니다.

### 🔷 이론적 기반을 다지고 싶다면 → 해석학·정보이론

솔직히 말씀드리면, **대부분의 실무자에게는 필요 없습니다.**
연구를 하거나 논문을 쓸 계획이 있을 때 고려하세요.

## E.4 이 코스에서 일부러 다루지 않은 것들

정직하게 밝혀 둡니다. 다음은 다루지 않았고, 필요해지면 따로 배우셔야 합니다.

| 주제 | 언제 필요해지나 |
|---|---|
| 극한의 엄밀한 정의 (ε-δ) | 이론 연구를 할 때 |
| 행렬 분해 (SVD, 고유값) | LoRA, PCA를 깊이 볼 때 |
| 확률분포의 수학적 성질 | 생성 모델을 만들 때 |
| 정보이론 (엔트로피, KL) | 손실 함수를 직접 설계할 때 |
| 볼록 최적화 이론 | 최적화 알고리즘을 연구할 때 |

> 💬 **이걸 안 배웠다고 불안해하지 마세요.**
> 현업 ML 엔지니어 상당수가 이것들을 모르고도 잘 일합니다.
> **필요해지는 순간이 오면, 그때 배우는 게 훨씬 빠릅니다.**
